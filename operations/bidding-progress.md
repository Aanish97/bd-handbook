  backend / real-time systems · healthcare automation · AI-accelerated delivery.
* **Connects:** ~83 spent · **163 remaining**.

* **Notable NO-GO calls (Connects saved):**
  * An evidence-first secure-AI-orchestration role — it screened for provable artifacts we
    don't have, so we skipped rather than send a thin or over-claimed proposal.
  * Several under-floor "lowball" posts — flat micro-budgets on expert-level scopes from
    high-volume gig-churners.
  * A location-gated role (a disguised full-time, North-America-only position).
  * Region-excluded and tool-gated posts (a tool we don't use; client regions we don't take).
* **System / decisions:**
  * Applied the new **anti-AI cover-letter standard** — each proposal opens on a specific
    technical observation about the client's problem, in plain text with no AI tells, and is
    honest about any capability gap instead of fabricating one.
  * Stood up a **durable new-job watcher** (5-minute cadence) that surfaces every new dev
    posting with a fit flag plus liveness / location / region / rate checks, and re-arms itself
    each session.
  * Added an **evidence-gate rule**: if a posting screens evidence-first and we have no provable
    artifact, it's a NO-GO — don't waste Connects.
  * Verified honesty on tool-specific claims (a GitHub dig before asserting any).
